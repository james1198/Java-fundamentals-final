This project is a Java-based Student Management System that allows users to store and manage student records. The program keeps track of each student’s ID, first name, last name, and GPA. It also allows users to search, update, remove, and analyze student information using both standard methods and recursive algorithms.

 to run it you must have java exstention pack instaled, open the termainal in vs code, paste in (javac *.java) and (java Main) after that, then you will follow the prompts after that.

you can Add a new student, Display all students, Search for a student by ID, Search for students by last name, Update student information, Remove a student, Sort students by ID, Sort students by last name, Calculate the average GPA, Find the highest GPA, Count students above a GPA threshold, Display the total number of students.

recursion was used for storing students by IDs by finding and sorting them, by storing students by name in the same way, calculating average and finding highest gpa taking all of the gpas adding them up and dividing them
